BYOM pages were permanently flagged red because new Date(null) produced epoch instead of Invalid Date. Extracted classifySequenceStatus() to status.js with null ?? NaN guard — BYOM pages now classified by preview/publish state.

The Problem

The Admin API returns sourceLastModified: null for BYOM (Bring Your Own Markup) pages that have no tracked edit source. Before the fix, buildSequenceStatus() immediately returned "No source" (negative/red) when the source date was absent — even for fully-previewed and published BYOM pages.

Root Cause

new Date(null) equals new Date(0), which is the Unix epoch — a valid date. The guard that was meant to catch "no source" only checked for undefined via new Date(undefined) = Invalid Date. Passing null slipped through and looked like a valid old date.

The Fix

Extracted classification logic to tools/page-status/status.js with a value ?? NaN guard before every new Date() call. Both null and undefined now produce Invalid Date, routing BYOM pages through the no-source branch which correctly inspects preview/publish state.
